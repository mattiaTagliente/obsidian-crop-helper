# Obsidian Crop Helper

Re-crop images extracted by the LLM_Harness content-mirror pipeline,
without leaving Obsidian. Right-click an embedded image, draw a new
rectangle on the original page render, save — the asset in `asset/` is
updated, the mirror raw stays immutable.

## Why

Lecture notes generated by the `lecture-images` skill insert pre-extracted
diagrams from `materiale/.content_mirror/`. When cascade_extract cannot
isolate a diagram (template-heavy LaTeX-vector slides), it falls back to a
full-page render and the user must crop the region of interest manually.
This plugin closes that loop inside Obsidian.

Multiple lecture sections often need different crops from the same source
page. Each crop is a distinct asset filename; the mirror render stays the
canvas they all draw from.

## Install

The plugin lives inside the vault at `.obsidian/plugins/crop-helper/`.
Build:

```bash
npm install
npm run build
```

Then reload Obsidian (`Ctrl+P` → `Reload app without saving`).

## Usage

- Right-click on an image embed → `Re-crop...`
- Draw a rectangle, hit Enter / double-click to save
- `Ctrl+P` → `Browse & re-crop images` for sweeping a whole mirror source
- `Ctrl+P` → `List pending crops` for render_fallback assets awaiting crop

The pre-positioned selection rectangle is the bbox of the previous crop
(read from `asset/.provenance.json`), so successive re-crops let you
adjust without redrawing from scratch.

## Architecture

- `src/main.ts` — plugin entry, command registration, context-menu wiring
- `src/crop-modal.ts` — single-image and browse modals, save pipeline
- `src/canvas-crop.ts` — pan/zoom canvas + rectangle selector
- `src/resolver.ts` — asset → mirror page lookup (provenance sidecar +
  fingerprint cascade); writeback policy
- `src/pdf-render.ts` — on-demand pdf.js rendering when the mirror has
  no pre-rendered page

`pNNN_render.png` files are treated as immutable: `writeBackToMirror` is
forced false regardless of match method. This keeps the re-crop canvas
intact across multiple distinct crops of the same page.
